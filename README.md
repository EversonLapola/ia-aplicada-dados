# ia-aplicada-dados

## Projetos

1. [P1 — Triagem](p1-triagem/) — classificação e triagem automática de demandas com IA.
2. [P2 — Text-to-SQL](p2-text-to-sql/) — perguntas em linguagem natural convertidas em SQL.
3. [P3 — Sentinela](p3-sentinela/) — monitoramento de dados com detecção de anomalias e alertas.
4. [P4 — MCP](p4-mcp/) — servidor MCP para expor fontes de dados a agentes de IA.
5. [P5 — Plugin](p5-plugin/) — plugin que empacota os fluxos de dados com IA.
